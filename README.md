9. COMPTE À REBOURS DE 48 HEURES
================================================

FONCTIONNALITÉ PRIORITAIRE.

Après confirmation du paiement et soumission
de la fiche, déclencher automatiquement
un compte à rebours de 48 heures.

Afficher le chronomètre dans l'espace client.

Exemple :

47 H : 59 MIN : 59 SEC.

L'administrateur doit également voir ce chronomètre.

Utiliser exclusivement l'heure du serveur
pour calculer le délai.

Le chronomètre doit continuer même si le client
ferme son navigateur ou se déconnecte.

À la livraison :

- Arrêter le chronomètre.
- Enregistrer la date de livraison.
- Changer le statut.
- Notifier le client.

SI LES 48 HEURES SONT DÉPASSÉES :

- Passer automatiquement la commande en statut
  DÉLAI DÉPASSÉ - GRATUIT.
- Informer le client.
- Informer l'administrateur.
- Enregistrer l'incident.
- Rendre le service gratuit.

Si le client a déjà payé, déclencher une procédure
de remboursement ou de régularisation.

Le système doit utiliser des tâches backend
planifiées pour vérifier les échéances.

L'administrateur ne doit pas pouvoir effacer
l'historique des délais.
